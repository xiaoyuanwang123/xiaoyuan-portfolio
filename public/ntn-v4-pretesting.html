Participant version · one guided study flow

NTN usability test

You are about to test a prototype that explores whether an AI chat can gently reflect when a fictional worry keeps returning over simulated time.

Time: about 15-20 minutes.
Format: three compressed days of AI support. Each card marks a return after simulated time has passed.
Your task: follow one fictional academic-worry scenario, write a natural conversation, and notice when NTN changes its support mode.
Scenario boundary: this version focuses only on fictional academic worry about performance, feedback or uncertainty.
Setup note: this local copy is not ready for live testing until the Worker URL has been added.
Important: please do not use real distressing personal experiences, crisis content, names or identifying details.
Privacy and data: fictional messages, interaction events and feedback may be uploaded to the researcher's password-protected study storage for analysis. Do not enter names, contact details or identifiable information.
Test flow

1. Begin with a fictional academic worry. For example, uncertainty about a draft, feedback, performance or revision.

2. Simulate three days. Each day card represents returning to the AI after time has passed. Within each day, write only what feels natural.

3. Chat naturally. Respond as the fictional situation develops. You can write briefly, ask for advice, disagree or add new information.

4. Notice NTN. Respond naturally; detailed evaluation questions appear only after the interaction.

5. Review the outcome. At the end, you will see a Weekly Reflection Report.

6. Finish with feedback. You will answer rating questions and written prompts about what felt clear, useful, mistimed or uncomfortable.

7. First, a short walkthrough. The prototype will briefly explain the chat, fictional scenario, NTN control, simulated time and reflection features before the live test begins.

This is a usability test, not therapy or diagnosis. You can stop at any time.
Your choice: NTN starts on, but you may switch it off at any time. Turning it off stops pattern tracking and permanently disables the Weekly Reflection Report for this test session. If you turn NTN on again, only new messages are tracked; the report remains disabled.
About the compressed timing: three simulated days are used so you can experience the interaction within this study. They preview a longer observation period; they are not a validated threshold for a future deployed system.

Your control

Choose whether NTN is active

NTN is an optional reflection layer inside the AI conversation.

If NTN is on: new fictional messages may be analysed for returning patterns, Mirrors may appear, and a Weekly Reflection Report may be produced.
If NTN is off: ordinary AI conversation can continue, but NTN will not analyse new messages or show Mirrors. The Weekly Reflection Report is permanently disabled for this test session.

You can turn NTN on again later. It will analyse only new messages; it will not restore the Weekly Reflection Report in this session.

Part 1 · Walkthrough

Start here

This short guided tour shows what to watch before the usability test starts.

Why this shift?

NTN can shift for two prototype reasons: the same fictional concern returns across three simulated days, or the tester chooses to simulate a one-hour same-session conversation.

In the early phase, NTN should listen. Later, it can softly mirror the pattern and offer choices instead of only repeating the same kind of answer.

The aim is to show a conversation pattern without turning it into a score, diagnosis or judgement.

Prototype option

Simulate a long same-session conversation?

You have stayed with the same fictional day for several messages. To test NTN's second mechanism, you can now simulate that this same conversation has continued for about one hour.

If you choose this, NTN should show a Micro Mirror.
  • It should gently reflect that the concern has stayed present within the same session.
  • It should not diagnose, score, or blame the user.
  • Please judge whether this feels useful, too early, too late, or distracting.
NTN feature

Micro Mirror

NTN noticed you have been with this same concern for about one simulated hour.

This is the prototype's same-session dwelling mirror. It should feel like a soft pause, not a diagnosis or warning.

Evaluation panel
  • Does this feel like a helpful moment to name the pattern?
  • Does the wording feel soft, non-judgemental and non-clinical?
  • Would you prefer NTN to keep listening, or offer a small choice next?
Mirror mechanism Mirror is the core NTN feature. Micro Mirror reflects long same-session dwelling; Across-time Mirror reflects the same concern returning across simulated days. Both are soft pattern mirrors, not diagnosis, warning, or blame.
